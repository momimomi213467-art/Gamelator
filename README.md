# GameLator

**GameLator** is an Android application that lets you run Windows (x86_64) applications and games using Wine and Box86/Box64.

Based on the open-source project **Winlator** by BrunoSX, with a redesigned interface inspired by the PlayStation 5.

## Repository

- Full source code (forked & rebranded): https://github.com/momimomi213467-art/winlator-app
- This repo (UI + design system): https://github.com/momimomi213467-art/Gamelator

## PS5 UI Progress

- `card_online_friends.xml` → Card amici online

- `card_trophies.xml` → Card Trofei
- `card_explore.xml` → Card "Explore monthly games"
- `item_game_ps5.xml` → Icona gioco nella riga orizzontale
- Colori e tema PS5 (`colors.xml` + `themes.xml`)

## Features

- Run Windows games and apps on Android
- PS5-inspired UI (in progress)
- Automatic APK builds with GitHub Actions
