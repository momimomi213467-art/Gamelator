# GameLator

**GameLator** is an Android application that lets you run Windows (x86_64) applications and games using Wine and Box86/Box64.

Based on the open-source project **Winlator** by BrunoSX, with a redesigned interface inspired by the PlayStation 5.

## Links

- Full source (forked & rebranded): https://github.com/momimomi213467-art/winlator-app
- This repo (UI + design system): https://github.com/momimomi213467-art/Gamelator

## PS5 UI & Assets already created

### Layouts
- `activity_main_ps5.xml` – Home screen
- `activity_settings_ps5.xml` – Settings screen
- `card_online_friends.xml` – Online Friends card
- `card_store.xml` – Store / Black Friday card
- `card_trophies.xml` – Trophies card
- `card_explore.xml` – Explore card
- `item_game_ps5.xml` – Game icon in horizontal row
- `item_settings.xml` – Settings list item
- `item_container_ps5.xml` – Container list item

### Design system
- `colors.xml` – PS5 color palette
- `themes.xml` – Dark PS5 theme
- `ic_gamelator_logo.xml` – Vector logo
- `ic_launcher.xml` – Adaptive icon
- `ps5_focus_ring.xml` – Focus ring for selected games
