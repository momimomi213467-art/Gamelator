# GameLator

**GameLator** is an Android application that lets you run Windows (x86_64) applications and games using Wine and Box86/Box64.

Based on the open-source project **Winlator** by BrunoSX, with a redesigned interface inspired by the PlayStation 5.

## Repository

- Source code (forked & rebranded): https://github.com/momimomi213467-art/winlator-app
- This repo: https://github.com/momimomi213467-art/Gamelator

## Features

- Run Windows games and apps on Android
- PS5-inspired UI (in progress)
- Automatic APK builds with GitHub Actions
